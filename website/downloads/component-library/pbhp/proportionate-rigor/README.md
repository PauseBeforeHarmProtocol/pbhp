# Proportionate Rigor

**Project:** Pause Before Harm  
**Category:** Protocol gates  
**Kind:** Tier routing  
**Component library version:** 1.0.0  
**Component source version:** PBHP v0.9.5 / site library 1.0.0  
**Release date:** 2026-07-18  
**Evidence state:** Specified

## Summary

Selects the lightest PBHP edition adequate to the stakes instead of applying one ritual to every decision.

## Mechanism

HUMAN and MIN support bounded decisions; CORE adds full evidence and receipt discipline; ULTRA adds independent review and reversal authority; ULTIMATE invokes the complete Project Shadow stack.

## Inputs

- Harm threshold
- Reversibility
- Complexity
- Authority and review needs

## Required outputs

- Selected tier
- Required controls
- Review structure
- Reason the tier is sufficient

## Known failure modes

- Under-routing high stakes
- Over-burdening routine work
- Tier selection after the preferred answer
- Treating ULTIMATE as prestige

## Current test state

Tier definitions are specified; burden, false-positive, and outcome calibration remain open.

## Next tests
