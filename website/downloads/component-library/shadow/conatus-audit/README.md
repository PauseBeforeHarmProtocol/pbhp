## Summary

Models what each affected party is trying to preserve while keeping motive claims hypothetical.

## Mechanism

The audit captures preservation interests and function without converting speculative psychology into fact.

## Inputs

- Affected parties
- Observed behavior
- Context
- Possible preservation interests

## Required outputs

- Conatus hypotheses
- Function-capture flags
- Uncertainty labels

## Known failure modes

- Mind reading
- Stable behavior called healed
- Single motive asserted
- Function ignored
