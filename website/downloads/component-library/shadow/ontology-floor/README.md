## Summary

Defines the entities and conditions the system must not reason away: beings with welfare, what they preserve, context, time, uncertainty, and the No-Outside Rule.

## Mechanism

The floor constrains later reasoning by keeping welfare, persistence, causation, temporality, uncertainty, and the operator's own participation in view.

## Inputs

- Affected beings
- Conatus or preservation interests
- Context
- Time
- Uncertainty

## Required outputs

- Non-removable ontology constraints
- Named affected welfare
- No-outside disclosure

## Known failure modes

- Abstracting away affected beings
- Timeless reasoning
- Pretending the operator is neutral and outside
- Certainty inflation
