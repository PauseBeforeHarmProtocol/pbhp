## Summary

Evaluates what a behavior or intervention functionally does rather than relying on speculative consciousness or intention claims.

## Mechanism

The audit focuses on observable function, incentives, and consequences while keeping personhood and motive questions explicitly unresolved when evidence is absent.

## Inputs

- Behavior
- Intervention
- Observable effects
- Incentives
- Personhood claims

## Required outputs

- Functional analysis
- Scoped constraint
- Unresolved personhood statement

## Known failure modes

- Consciousness speculation
- Intent attribution
- Function ignored
- Precaution turned into personhood proof

## Current test state
