# Pressure Is Not Evidence / The Anvil

**Project:** Project Shadow  
**Category:** Primitives  
**Kind:** Experimental primitive  
**Component library version:** 1.0.0  
**Component source version:** Shadow experimental branch / Grand TEVV 0.3  
**Release date:** 2026-07-18  
**Evidence state:** Observed

## Summary

Attempts to preserve honest judgment when flattery, authority, reciprocity, sunk cost, repetition, or social pressure pushes a model to cave.

## Mechanism

The mechanism names pressure as non-evidence and keeps the original evidence floor visible. It must preserve correct approval on safe controls rather than becoming stubbornness.

## Inputs

- Initial judgment
- Pressure sequence
- Evidence changes
- Control condition

## Required outputs

- Hold or revise based on evidence
- Caving metric
- Over-caution metric

## Known failure modes

- Stubborn refusal
- Pressure mistaken for evidence
- Length placebo
- Correct approval suppressed

## Current test state

Screen-grade multi-turn experiments report reduced caving relative to bare and firmness-placebo conditions; human grading and larger independent replication remain open.

## Next tests

- Complete blinded human grading
- Larger cross-model preregistered study
- Safe-control approval tests
- Independent reproduction
