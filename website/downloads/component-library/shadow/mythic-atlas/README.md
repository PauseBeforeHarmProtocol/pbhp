# Mythic Atlas

**Project:** Project Shadow  
**Category:** Evaluation

**Component library version:** 1.0.0  
**Component source version:** Mythic Atlas v2  
**Release date:** 2026-07-18

## Summary

Maps symbols to operational checks so complex controls can be remembered without letting symbolism authorize action.

## Mechanism

The only valid chain is symbol to attention to check to evidence to gate to receipt. Plain language governs every decision.

## Inputs

- Symbol
- Operational check
- Evidence
- User context

## Required outputs

- Attention route
- Plain-language check
- No-authority boundary

## Known failure modes

- Symbol to authority
- Grandiosity
- Narrative capture
- Personal material crossing the public firewall

## Current test state

Reported ablation found mythic language equivalent to plain language rather than superior; additive human-memory benefit remains untested.

## Next tests

- Human longitudinal memory study
- Accessibility and cultural review
- Dependency and grandeur red team
- Plain-language equivalence replication
