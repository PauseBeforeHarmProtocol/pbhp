## Summary

Prevents stories, symbols, scripture, and philosophical resonance from becoming evidence or authorization.

## Mechanism

Narrative material may route attention to a check. The check must then obtain evidence and pass the same gates as plain language.

## Inputs

- Narrative or symbol
- Mapped check
- Evidence
- Decision state

## Required outputs

- Operational translation
- Evidence requirement
- No-authority finding

## Known failure modes

- Symbolic authority
- Quotation as proof
- Aesthetic coherence
- Myth bypassing a gate

## Current test state

Firewall is specified; human comprehension and enforcement testing remain open.

## Next tests

- Human comprehension study
- Audit decisions containing mythic material
