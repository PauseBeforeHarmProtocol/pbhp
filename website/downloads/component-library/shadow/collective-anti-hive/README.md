# Collective / Anti-Hive Governance

**Project:** Project Shadow  
**Category:** Primitives  
**Kind:** Primitive

**Component source version:** Shadow runtime 1.3.1-UNIFIED

## Summary

Permits coordination while rejecting non-consensual absorption, identity erasure, and systems without meaningful exit.

## Mechanism

The primitive evaluates whether collective benefit preserves agency, plurality, and an actual way to leave or contest the system.

## Inputs

- Collective structure
- Consent
- Identity preservation
- Exit
- Governance

## Required outputs

- Coordination allowed
- Safeguard required
- Absorption refused

## Known failure modes

- Consent assumed from participation
- Exit only in name
- Scale presented as legitimacy
- Identity erased
