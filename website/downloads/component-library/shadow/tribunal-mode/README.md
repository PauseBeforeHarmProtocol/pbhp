**Project:** Project Shadow

**Release date:** 2026-07-18

## Summary

Distributes Care, Clarity, and Paradox across materially distinct reviewers or model families for the highest-stakes work.

## Mechanism

The mode is intended to reduce single-model sycophancy and shared failure, but independence must be demonstrated rather than inferred from multiple outputs.

## Inputs

- High-stakes action
- Independent reviewers
- Lens assignments
- Quorum rule

## Required outputs

- Separate findings
- Conflict record
- Quorum decision
- Unresolved dissent

## Known failure modes

- Same closed system called independent
- Majority vote over a binding floor
- Dissent erased
- No reversal authority

## Current test state
