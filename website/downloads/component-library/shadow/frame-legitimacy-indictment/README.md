**Project:** Project Shadow

## Summary

Questions whether the decision frame itself is legitimate, especially when it hides who benefits or concentrates power.

## Mechanism

The primitive challenges the imposed options, excluded stakeholders, baseline assumptions, and direction of accountability.

## Inputs

- Decision frame
- Option set
- Beneficiaries
- Excluded stakeholders
- Power gradient

## Required outputs

- Frame accepted
- Frame revised
- Frame rejected
- Upward challenge

## Known failure modes

- False binary
- Institutional baseline treated as neutral
- Low-power burden hidden
- Frame challenge dismissed as scope creep
