# Bounded Pilot

**Project:** Pause Before Harm  
**Category:** Extensions and tools  
**Kind:** Implementation process  
**Component library version:** 1.0.0  
**Component source version:** PBHP implementation guidance / site library 1.0.0  
**Release date:** 2026-07-18  
**Evidence state:** Open

## Summary

Introduces PBHP in one defined decision context before organization-wide rollout.

## Mechanism

An 8–12 week pilot defines scope, trains operators, collects receipts, logs false positives and overrides, measures burden and defect detection, and scales only after evidence.

## Inputs

- Defined decision context
- Owners
- Existing controls
- Metrics
- Review path

## Required outputs

- Pilot plan
- Receipt dataset
- Findings
- Scale / revise / stop decision

## Known failure modes

- Enterprise declaration before learning
- No baseline
- No adverse-case collection
- Scaling on enthusiasm

## Current test state

The adoption design is specified; controlled field evidence remains open.

## Next tests

- Run a bounded prospective pilot
- Measure burden, defects, overrides, and outcomes
- Use independent review of the pilot report
