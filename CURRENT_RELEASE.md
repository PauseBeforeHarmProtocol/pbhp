# PBHP current release status — July 18, 2026

The canonical PBHP protocol and Python implementation remain **version 0.9.5**. The repository source tree and changelog identify v0.9.5, while the GitHub Releases surface observed on July 18 still showed v0.9.0 as the latest published release. The source/release-page mismatch should be corrected by cutting a v0.9.5 release after maintainer review.
